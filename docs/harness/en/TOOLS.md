## Per-host setup

| Capability | OpenCode | Claude Code | Codex | Cursor |
|---|---|---|---|---|
| Instructions | `AGENTS.md` + `opencode.json` | `CLAUDE.md` → `@AGENTS.md` | `AGENTS.md` | `AGENTS.md` (native) |
| Skills | `.agents/skills/` (canonical) and `.opencode/skills/` (native, takes precedence) | `.claude/skills` (symlink) | `.agents/skills/` | `.agents/skills/` (native) |
| Agents | `.opencode/agent/` (+ optional when enabled) | `.claude/agents/` (+ optional when enabled) | *(no subagents)* | `.cursor/agents/` (+ optional when enabled) |
| OpenSpec commands | `.opencode/commands/` | `.claude/commands/opsx/` | `.codex/prompts/` | `.cursor/commands/opsx-*` |
| MCP | `opencode.json` → `mcp` | Claude configuration | Codex configuration | `.cursor/mcp.json` → `mcpServers` |
| Model | `model` / `small_model` | `model` | `model` | `model: inherit` in each subagent |

The bootstrap generates adapters. Commands are generated by `openspec init --tools <host>`
(`openspec update` regenerates instructions but does not accept `--tools`).

### Cursor specifics

- **Instructions:** `AGENTS.md` is the only source. The template does not create `.cursor/rules/*.mdc`.
- **Skills:** Cursor discovers `.agents/skills/` natively; there is no `.cursor/skills/` copy or link.
  Invoke them as `/name` or `@name`.
- **Subagents:** `.cursor/agents/<role>.md` with `name`, `description` and `model: inherit`. The
  template never sets `readonly`: it blocks file edits and the `reviewer` must write its report.
- **Commands:** `openspec init --tools cursor` writes `.cursor/commands/opsx-*`. Cursor 2.4+ can migrate
  commands to skills; the generated commands keep working meanwhile.
- **MCP:** `.cursor/mcp.json` is created from `.atlas/hosts/cursor/mcp.json` **only if missing** and is
  announced. After that it belongs to the project and is never overwritten.
- **Permissions:** `.cursor/permissions.json` and `.cursor/cli.json` are a **user option**. They apply to
  the whole project and do not distinguish roles, so the template neither creates nor versions them.

## Context7 (documentation MCP)

**What for:** verify APIs, versions and syntax before proposing or using a library.

| Host | Configuration |
|---|---|
| OpenCode | `mcp.context7` block in `opencode.json` (already included in the host template) |
| Claude Code | Add the remote MCP server `https://mcp.context7.com/mcp` |
| Codex | Add the MCP server in its configuration |
| Cursor | `mcpServers.context7` in `.cursor/mcp.json` (the bootstrap creates it only if missing) |

**Project rule:** never propose or use a library without verifying it with Context7; if you cannot, justify
it in `design.md`.

⚠️ **Confidentiality:** queries go to an external service. Never include proprietary code, secrets or
personal data.

## Persistent memory

| Option | When |
|---|---|
| **Engram** | Recommended if unsure: local memory plus git sync |
| Other | Mem0, Letta or the host's native memory |
| None | The flow still works; the summary goes to the chat and the PR |

- `.engram/` is **not versioned** by default.
- If you sync across machines, decide first what is shared.
- Memory may contain sensitive context: never store secrets.

## gitleaks (secrets)

It is a **git hook**, not an agent hook: it works in all three hosts.

```bash
brew install gitleaks
git config core.hooksPath .githooks
```

`.githooks/pre-commit` is a dispatcher. `20-gitleaks.sh` scans the staged changes and blocks the commit
if it detects secrets; if gitleaks is not installed, it warns and does not block. The base-branch guard
still runs. Detail: [`HOOKS.md`](HOOKS.md).

## Database MCP

Useful to inspect data during QA or analysis.

- Use **read-only** credentials.
- Point to **development data**, never production.
- Do not version the connection string: use `.env` (ignored) or the host's local configuration.

## Common problems

| Symptom | Fix |
|---|---|
| Context7 does not respond | Check the network and MCP URL; the flow can continue without it |
| Memory does not persist | Check the host configuration and that `.engram/` exists |
| gitleaks does not run | `git config core.hooksPath .githooks` |
| Codex does not invoke a skill | Use `$name` or `/skills`; there are no subagents |
| Cursor does not show a subagent | Check `.cursor/agents/<role>.md` and restart Cursor |
| Cursor cannot write the reviewer report | Do not add `readonly: true` to the adapter; it blocks every edit |
| `opsx-*` commands are missing | `openspec init --tools <host>` (or `openspec update` to regenerate) |
