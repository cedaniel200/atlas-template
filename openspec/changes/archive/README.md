# Archivo de cambios

Aquí se mueven los cambios ya archivados con `openspec archive <cambio>`, en subcarpetas
`<YYYY-MM-DD>-<nombre>/`.

- **No se edita a mano**: el contenido es histórico.
- El delta de specs se fusionó en `openspec/specs/` al archivar.
- Si necesitas revertir una decisión, propón un cambio nuevo; no reescribas el archivo.

> Este directorio debe existir para que `openspec doctor` reporte el root como healthy.
