# ADR Preferences

preferred-style: madr-minimal

Nota: Los ADRs existentes en el proyecto usan una adaptación de MADR minimal en español con las secciones: Contexto, Decisión, Consecuencias, Alternativas consideradas.

When `preferred-style` is `unset`, ask the user which ADR style they prefer before drafting an ADR, then update this file with one of:

- `madr-full`
- `madr-minimal`
- `nygard`
- `y-statement`
- `custom`

If the user chooses `custom`, record a short note describing the preferred structure.
